# split by domain (docs/nofap/DESIGN.md 3.3).

# A host under a rule of this file is never blocked by the list or by a
# keyword. While it is in front, the screen check runs at its "signal" cadence,
# and a block-grade word in the path (reddit.com/r/...) counts as a signal. The
# user can block any of them whole in "modo estrito"; that is a user block, so
# nothing here is on never-block.txt.
#
# Syntax: the same as never-block.txt (NAME, TLD and SECOND-LEVEL rules; "#"
# lines and empty lines ignored; no end-of-line comments). Only NAME rules are
# used here.
#
# Image search: Google and Bing serve image results from the same host as web
# search, so they cannot be listed here without putting every search under the
# screen check. A block-grade word in the window title covers them instead.
# Only search engines with a host of their own for images are listed.
#
# Hand-maintained. After a change run: python3 scripts/nofap/build_blocklist.py
