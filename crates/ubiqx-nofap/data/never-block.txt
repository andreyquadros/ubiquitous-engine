# never-block.txt: names that are never blocked.
#
# Used three ways (docs/nofap/DESIGN.md 2.2, 3.3, 3.4):
#   1. the build script removes these names from the embedded list;
#   2. the matcher treats them as the built-in allowlist: no list entry and no
#      keyword or TLD rule blocks them;
#   3. the elevated helper refuses to write any name under them to the hosts file.
#
# Syntax (the same in mixed.txt and never-capture.txt). A line that is empty or
# starts with "#" is ignored; there are no end-of-line comments. Every other
# line is one rule in lower-case ASCII:
#
#   example.com   NAME: two or more labels. Covers the name and every subdomain.
#   gov           TLD: one label. Covers every name whose last label is it.
#   gov.*         SECOND-LEVEL FORM: one label followed by ".*". Covers every
#                 name that has that label immediately before its last label:
#                 gov.br, x.gov.br, a.b.gov.uk, x.gov.wales. It does not cover
#                 "gov" as a top-level domain (write "gov" for that), nor
#                 xgov.br, nor gov.example.br.
#
# A TLD or SECOND-LEVEL rule decides at every depth. For a NAME rule the
# matcher's longest match applies: a more specific listed subdomain (the list
# keeps adult.contents.fc2.com while fc2.com is allowed) stays blocked.
#
# The SECOND-LEVEL form is matched by shape, without the Public Suffix List, so
# "gov.*" also covers a private name such as gov.com. The build prints every
# listed name such a rule removed (section 3 of
# docs/nofap/research/blocklist-top10k-review.txt) so that a person can see it.
#
# What belongs here: names whose blocking would break the computer, sign-in,
# updates, payments or the product itself; public-sector and academic name
# spaces; sexual-health, education and recovery sites; ordinary sites whose name
# happens to contain a block-grade keyword. What does not belong here: a
# general platform that also carries adult material (that is mixed.txt), or a
# hosting suffix where anybody can publish (blogspot, azurewebsites): an entry
# here also switches the vision check off for the name.
#
# Hand-maintained. After a change run: python3 scripts/nofap/build_blocklist.py
