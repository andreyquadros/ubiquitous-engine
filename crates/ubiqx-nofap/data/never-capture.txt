# never-capture.txt: sites whose window is never pictured by the screen check
# and never blocked (docs/nofap/DESIGN.md 3.3, 4.2).
#
# These are the places where a picture would show somebody's money, mail,
# documents, health or passwords. The rule holds for the whole name and its
# subdomains, whatever the page shows.
#
# Syntax: the same as never-block.txt.
#
#   example.com   NAME: two or more labels. Covers the name and every subdomain.
#   gov           TLD: one label. Covers every name whose last label is it.
#   gov.*         SECOND-LEVEL FORM: covers every name that has the label "gov"
#                 immediately before its last label (x.gov.br, x.gov.wales).
#
# "#" lines and empty lines are ignored; there are no end-of-line comments.
# Banks, payment services, the public sector and the AI providers are repeated
# here from never-block.txt on purpose: each file is read on its own.
#
# Hand-maintained. After a change run: python3 scripts/nofap/build_blocklist.py
